# @saicmotor/plugin-attendance

saicmotor 考勤打卡插件。

## 依赖

- 核心: `^0.8.0`

## 能力

- 考勤记录查询
- 补卡申请提交

## 安装

```bash
saicmotor plugin install attendance --registry=<内部registry>
```

## 命令

```bash
saicmotor attendance records query          # 查询考勤
saicmotor attendance corrections submit     # 提交补卡
```
